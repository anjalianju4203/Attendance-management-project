**Attendance Management System**

A smart and user-friendly Attendance Management System developed using **Python, MySQL, and Tkinter**. This application simplifies student record management, batch-wise attendance tracking, attendance report generation, and student marks management.

- Manage and update student records.
- Mark and maintain daily attendance.
- View batch-wise attendance details.
- Generate individual student attendance reports.
- Add and manage student marks.
- Search student records quickly and efficiently.

**A simple, efficient, and organized solution for managing academic records and attendance in one place!**
